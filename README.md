# QA Portfolio — Vladislav Vygolka

Personal portfolio website of a QA Engineer.

## Contents

- `index.html` — standalone website
- `robots.txt` — crawler access rules
- `sitemap.xml` — sitemap for search engines
- `google8cd4acea756db89e.html` — Google Search Console verification file

## Local preview

Open `index.html` in a browser. The page uses Tailwind CDN and Google Fonts, so an internet connection is required for those external assets.

## Deployment

The site is currently deployed on Vercel. The repository is a source backup and can be connected to another static hosting provider.
